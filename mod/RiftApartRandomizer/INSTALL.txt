Ratchet & Clank: Rift Apart - Randomizer 9.0
============================================
For the PC (Steam) game with rivet_hook 2.0.x. Everything is in this folder. ARSENAL_RESTORED is
optional: its weapons join the randomizer automatically when it is installed
(docs\ARSENAL_RESTORED.md). Nothing here changes the game's own files.

9.0 REMOVES THE ZURKIE'S HUB. A New Game plays the prologue (the parade on Corson V), then Nefarious
City, then Sargasso, exactly as the game does. The randomizer moves you nowhere, starts no mission
and swaps no hero; you travel with the ship's planet menu. Rewards, the shop, armor, Coordinates and
locked levels work as before. Your 8.5.2 edits are kept (your defaults in 02, Punk and Reaver owned
from the start). See docs\CHANGELOG.md. 9.0 HAS NOT RUN IN YOUR GAME YET:
docs\VERIFICATION_REPORT.md says exactly what has been verified, and how.

Play on a SPARE save slot and back up your saves first.

BEFORE YOU START
  1. Back up your saves: Documents\Ratchet & Clank Rift Apart (copy the folder somewhere safe).
  2. rivet_hook 2.0.x must be installed (hid.dll + rivet_hook.dll next to RiftApart.exe).
  3. ARSENAL_RESTORED (optional), either version:
       - Overstrike version: keep it installed through Overstrike.
       - rivet_hook version: drag its zip onto companion\Install-ArsenalRestored.bat. By hand: put
         the folder that holds info.json in <game>\mods named ARSENAL_RESTORED, and its .lua files
         in <game>\scripts.

INSTALL (also when updating from 8.x)
  1. In <game>\scripts, delete EVERY old randomizer .lua file (all *_rando_*.lua from older kits,
     including any 00_rando_seed.lua, 07_rando_testmode.lua and 08_rando_probe.lua).
     DELETE 15_rando_hub.lua: 9.0 has no such file. Leave the ARSENAL_RESTORED .lua files alone.
  2. Copy the 13 files from this kit's scripts folder into <game>\scripts:
       01_rando_data  02_rando_generator  03_rando_campaign  04_rando_settings
       05_rando_bindings  06_rando_capabilities  09_rando_real  10_rando_runtime  11_rando_campaign
       12_rando_shop  13_rando_armor  14_rando_travel  16_rando_testtravel
     Use this kit's 04_rando_settings.lua: it is your 8.5.2 file without the hub lines, preset
     "balanced". An 8.x settings file still works: rivet.log names every hub option it ignores,
     and preset "hub" becomes "balanced" ("hub_chaos" becomes "chaos").
  3. Copy rivet.toml and rando_give.dll next to RiftApart.exe, replacing the old ones.
     rando_give.dll is v6, the same binary as 8.0-8.5. If you added your own [assets] paths to
     rivet.toml, keep them.
  4. Copy the companion folder to <game>\rando_companion, replacing the old one.
  5. Check the install: start the game and look in rivet.log (next to RiftApart.exe) for
       RANDO-KIT all 13 scripts are 9.0.0
     If it says a file is missing, from another kit, or that 15_rando_hub.lua must be deleted,
     repeat steps 1-2.

YOUR SEED AND PROGRESS
  9.0 seeds are new seeds (generator 9.0, share code RA9): start a NEW GAME. The previous runs'
  files stay in companion\randomizer_saves and are never touched.

NEW GAME (docs\PLAYING.md has the full walkthrough)
  1. Start companion\Start-Companion.bat, then the game. Keep the companion window open: it saves
     your randomizer progress, sends a random seed, checks for ARSENAL_RESTORED and writes the
     spoiler (companion\randomizer_saves\spoilers - only open it if you want spoilers).
  2. Choose NEW GAME on a spare slot. The parade plays as usual; your start items arrive.
  3. Play on: the game takes you to Nefarious City, then Sargasso. After that, fly with the ship's
     planet menu as the story opens planets. ; shows the status. The old F keys work too.
  4. Saving and loading is normal.

IF SOMETHING GOES WRONG
  rivet.log has every step (search for RANDO-ERROR, RANDO-KIT, RANDO-TRAVEL, RANDO-REAL).
  - docs\KNOWN_ISSUES.md, docs\RECOVERY.md.
  - With locked levels (preset campaign / chaos / everything): Ctrl+; twice opens the planet you
    were last sent back from.

FILES
  scripts\       the randomizer (13 files)
  rivet.toml     rivet_hook's settings (loads rando_give.dll, ARSENAL_RESTORED paths)
  rando_give.dll the native helper (v6); rando_give_source\ rebuilds it byte for byte (build.sh)
  companion\     saving, random seeds, spoiler logs, the ARSENAL_RESTORED installer and check
                 (PowerShell, comes with Windows); companion\research\ read-only research tools
  extras\        test mode and developer tools (not needed to play; do not copy for a real run)
  docs\          PLAYING.md (start here), CHANGELOG.md, VERIFICATION_REPORT.md, KNOWN_ISSUES.md,
                 TESTING.md (with the playthrough checklist), CONFIGURATION.md, TEST_TRAVEL.md,

                 LEVELS.md, NEW_GAME.md, MIGRATION.md, RECOVERY.md, COMPATIBILITY.md,
                 FEATURES_AND_LIMITATIONS.md, VERIFIED_IN_GAME.md, DESIGN.md, CAMPAIGN.md,
