Ratchet & Clank: Rift Apart Randomizer - DEVELOPMENT KIT (v0.62-DEV4)
=================================================================
This folder is the development kit. Players get the release package instead
(python tools/build_public_release.py; its docs are in release/).

LAYOUT
  scripts\         the release's Lua scripts (dev 10.35: nothing else). rivet_hook loads scripts\*.lua in
                   name order. Release scripts (all go into <game>\scripts):
                     01_rando_data  02_rando_generator  03_rando_campaign  04_rando_settings
                     05_rando_bindings  06_rando_capabilities  09_rando_real  10_rando_runtime
                     11_rando_campaign  12_rando_shop  13_rando_armor  14_rando_travel
                     15_rando_hub (optional: planet shuffle; without it the game's own story plays)
                     16_rando_spawners  enemy  boss  (optional, dev 10.12: the Enemy and Boss
                       Randomizers, both OFF until their key; enemy and boss need 16_rando_spawners)
                     chaos  (optional, dev 10.13: the Chaos Randomizer, OFF until BACKSPACE; NO
                       safety guards; needs 16_rando_spawners; never in a player package)
                     17_rando_omega  (optional, dev 10.15: sets the game's Omega flag for an Omega
                       reward, docs/OMEGA.md; never in a player package until it has run in the game)
  dev_scripts\     dev 10.35: OPTIONAL developer diagnostics, never in a release and never needed to play
                   (named dev(name).lua; copy one into <game>\scripts only for a test that asks for it):
                     dev(keys)        the developer keys ; ] [ / ' and the old F keys
                     dev(testtravel)  test travel (keys . and , with test_travel = true)
                     dev(testmode)    F10 / F11 fake progress, Ctrl+F10 x2 reset, the mission lab
                     dev(probe)       script-node probe (NUMPAD keys)
                     dev(vtables)     data for dev(probe)
                     dev(item_ids)    data for dev(probe)
                     dev(spawnprobe)  read-only spawner evidence (RANDO-SPAWNPROBE lines; dev 10.20)
                     dev(spawnproof)  controlled enemy replacements on Zurkon (RANDO-SPAWNPROOF lines; v6, dev 10.26;
                                      dev 10.27: stands down while the Enemy Randomizer is ON)
  rivet.toml       rivet_hook settings (copy next to RiftApart.exe)
  rando_give.dll   the native helper (copy next to RiftApart.exe); rando_give_source\ rebuilds it
                   dev 10.24: this IS v7 (it publishes the SceneManager dev(spawnproof) needs; it ran in your game
                   in round32). rando_give_source\release_v6\ keeps the v6 binary for public packages.
                   (dev 10.21-10.23: the v7 build was in rando_give_source\dev_build and had to be copied by hand)
  companion\       the companion (saving, random seeds, spoilers); companion\research\ is dev-only
  docs\            development notes and research (not shipped)

INSTALL FOR DEVELOPMENT
  1. Back up Documents\Ratchet & Clank - Rift Apart. Use a spare save slot.
  2. rivet_hook 2.0.x must be installed (hid.dll + rivet_hook.dll next to RiftApart.exe).
  3. Delete every old *_rando_*.lua and dev(*).lua from <game>\scripts, then copy everything in
     scripts\ into <game>\scripts (and only the developer files a test asks for from dev_scripts\).
  4. Copy rivet.toml and rando_give.dll next to RiftApart.exe, and companion\ to
     <game>\rando_companion.
  5. Start rando_companion\Start-Companion.bat, then the game. rivet.log shows
       RANDO-KIT release v0.60 (kit 10.0.24)
       RANDO-KIT all required scripts are 10.0.24
     A dev(name).lua of an older kit left in <game>\scripts is named in a RANDO-ERROR RANDO-KIT line: delete it.

ENEMY RANDOMIZER (dev 10.33)
  enemy_compat = "all" in scripts\04_rando_settings.lua (the default): every regular enemy LOADED ON THE LEVEL can become
  every other of its movement group (walkers / flyers / turrets), Nefarious troopers included, and a spawner that already
  spawned changes for its next spawns. enemy_mix_movement = true also mixes the groups (off since dev 10.32: round42's
  walkers at flyer spawns could not be killed). A replacement that is still alive after a fight (6 other deaths, 45 s)
  or while nothing on the level died for 40 s is put back. enemy_compat = "verified" is 10.30's behaviour.
  The game can only spawn an enemy whose template is loaded on the level: on Cordelion's first fights that is Nefarious
  troopers only. Ctrl+- names the species loaded where you are. Enemies of OTHER planets need an asset-level swap (not
  in this kit; rivet.log's "ASSET" lines collect what it needs).
  dev 10.33: the enemy kinds every log has named are built in, so a new save randomizes from its first fight; the
  pirate robot shooter is never used as a replacement (it could not be killed as one).

KEYS
  Players: 0 planet shuffle on/off (off by default), Ctrl+0 twice gives randomizer items back.
           - Enemy Randomizer on/off, = Boss Randomizer on/off (both ON in this dev kit's 04 file; the
           save remembers them). Ctrl+- / Ctrl+= show what each changed here. dev 10.27: only the Enemy
           Randomizer changes enemies in the game (it needs this rando_give.dll, v7).
           BACKSPACE Chaos Randomizer on/off (off by default; no protection; while on, the
           Boss Randomizer pauses). Ctrl+BACKSPACE shows what it changed.
  Everything else needs dev(keys).lua (see the top of that file).

DEV4 FOLLOW-UP (10.0.24)
  - Enemy Randomizer: SpawnFactory handles from spawn events are now queued for targeted discovery
    before the full-level scan. The spawn that raised the event is never changed; this can arm a
    multi-wave factory for later spawns. No guarantee for one-shot spawners.
  - Omega: if the four known inventory component names are absent, the live hero's component
    classes and relevant component metadata / Prius bytes are logged once. Read-only; no Omega
    flag writes are enabled by this diagnostic.
  - Remove every old dev(*).lua from <game>\scripts. In particular, dev(spawnprobe).lua is not
    needed for normal play and can exceed the 8 ms frame budget. Keep diagnostics in dev_scripts\.
