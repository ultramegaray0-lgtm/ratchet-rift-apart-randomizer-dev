Ratchet & Clank: Rift Apart - Randomizer 8.4 (release candidate)
===============================================================
For the PC (Steam) game with rivet_hook 2.0.x. Everything is in this folder. ARSENAL_RESTORED is
optional: its weapons join the randomizer automatically when it is installed
(docs\ARSENAL_RESTORED.md). Nothing here changes the game's own files.

8.4 is a STABILIZATION release of 8.3: no new features, the same seeds, fixes for round 20.
  - Every destination is played as its own hero, checked with the game. In round 20 a stale saved
    hero made Torren IV and Viceron run as Ratchet, and their stories never started. Four heroes
    in the registry were also wrong.
  - Hub trips start the story first, then travel. A story stuck at "go to <planet>" is reloaded
    once (out to Zurkie's and straight back).
  - Weapon types are no longer mislearned from a load. Ms. Zurkon's slots are read the way the
    game stores them. The game itself now detects ARSENAL_RESTORED.
  - A kit check reports a scripts folder that mixes kits. Test travel is OFF in this kit.
  See docs\CHANGELOG.md. 8.4 HAS NOT RUN IN YOUR GAME YET: docs\VERIFICATION_REPORT.md says
  exactly what has been verified, and how.

Play on a SPARE save slot and back up your saves first: the randomizer writes mission states,
level bits and planetary travel into the game's memory, and moves the hero with warps.

BEFORE YOU START
  1. Back up your saves: Documents\Ratchet & Clank Rift Apart (copy the folder somewhere safe).
  2. rivet_hook 2.0.x must be installed (hid.dll + rivet_hook.dll next to RiftApart.exe).
  3. ARSENAL_RESTORED (optional), either version:
       - Overstrike version: keep it installed through Overstrike.
       - rivet_hook version: drag its zip onto companion\Install-ArsenalRestored.bat. By hand: put
         the folder that holds info.json in <game>\mods named ARSENAL_RESTORED, and its .lua files
         in <game>\scripts.

INSTALL (also when updating from 8.3)
  1. In <game>\scripts, delete EVERY old randomizer .lua file (all *_rando_*.lua from older kits,
     including any 00_rando_seed.lua, 07_rando_testmode.lua and 08_rando_probe.lua). Leave the
     ARSENAL_RESTORED .lua files alone.
  2. Copy the 14 files from this kit's scripts folder into <game>\scripts:
       01_rando_data  02_rando_generator  03_rando_campaign  04_rando_settings
       05_rando_bindings  06_rando_capabilities  09_rando_real  10_rando_runtime  11_rando_campaign
       12_rando_shop  13_rando_armor  14_rando_travel  15_rando_hub  16_rando_testtravel
     Use this kit's 04_rando_settings.lua and put your seed / preset back in. An older settings
     file still works, but new options then use their defaults (rivet.log says so).
  3. Copy rivet.toml and rando_give.dll next to RiftApart.exe, replacing the old ones.
     rando_give.dll is v6, the same binary as 8.0-8.3. If you added your own [assets] paths to
     rivet.toml, keep them.
  4. Copy the companion folder to <game>\rando_companion, replacing the old one.
  5. Check the install: start the game and look in rivet.log (next to RiftApart.exe) for
       RANDO-KIT all 14 scripts are 8.4.0
     If it says a file is missing or from another kit, repeat steps 1-2.

YOUR SEED AND PROGRESS
  8.4 makes the same seeds as 8.3 (same fingerprint), so 8.3 progress carries over. For a full
  playthrough, start a NEW GAME (the randomizer starts its progress over with it; the previous
  run's file is kept).

NEW GAME (docs\HUB.md has the full walkthrough)
  1. Start companion\Start-Companion.bat, then the game. Keep the companion window open: it saves
     your randomizer progress, sends a random seed, checks for ARSENAL_RESTORED and writes the
     spoiler (companion\randomizer_saves\spoilers - only open it if you want spoilers).
  2. Choose NEW GAME on a spare slot. Pick up the wrench in the parade: you are taken to Zurkie's,
     "Zurkie's Battleplex: Coordinates for X and Y".
  3. ] shows a destination, Ctrl+] goes there (hero and story first). ; shows the status.
     [ twice goes back to Zurkie's. / starts (or reloads) the story of the planet you are on.
     Ctrl+[ twice finishes a destination whose story won't start. The old F keys work too.
  4. Saving and loading is normal.

IF SOMETHING GOES WRONG
  rivet.log has every step (search for RANDO-HUB, RANDO-ERROR, RANDO-KIT).
  - docs\HUB.md "If it goes wrong", docs\KNOWN_ISSUES.md, docs\RECOVERY.md.
  - hub_runtime = false in 04_rando_settings.lua plays the seed without the hub.
  - story_prime_before_travel = false / story_reload_stuck = false switch off 8.4's story changes.

FILES

  rivet.toml     rivet_hook's settings (loads rando_give.dll, ARSENAL_RESTORED paths)

  companion\     saving, random seeds, spoiler logs, the ARSENAL_RESTORED installer and check

  extras\        test mode and developer tools (not needed to play; do not copy for a real run)
