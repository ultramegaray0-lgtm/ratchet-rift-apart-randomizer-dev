# Enemy Randomizer V2.0.1 — MAX patch

## What changed

This patch upgrades the existing all-planet .stage builder to **2.0.1**. It is an evidence-policy and build-delivery update, not a claim that every enemy in the game has been replaced.

### Latest runtime evidence bundled

The exact 2026-11-26 01:53:24 verdict file is now bundled under
`tools/stage_enemies/evidence/verdicts_2026-11-26_015324.json`.

Its 170 observed changes classify as:

| Runtime verdict | Count | V2 treatment |
|---|---:|---|
| WORKED | 5 | Pin the exact replacement UID observed in-game |
| NO SPAWN | 31 | Keep the original enemy; never force these stale replacements |
| ORIGINAL SPAWNED | 0 | No instances in this run |
| NOT REACHED | 134 | Remain eligible for a new seeded selection |

The report's 40 "not changed by .stage" entries are pre-existing zone-data replacement kinds, not 40 additional successful patches.

### Critical evidence-precedence correction

The previous builder had two conflicting rules: it let an older WORKED verdict survive a later NO SPAWN, and its four hard-coded historical pins could bypass a failure verdict. That is now fixed:

- Later observed results supersede earlier observed results.
- NOT REACHED is not an observation and cannot erase a previous WORKED or failure.
- A latest WORKED pins the exact UID from that run, including when it differs from an older hard-coded pin.
- A latest NO SPAWN or ORIGINAL SPAWNED suppresses the historical pin and leaves that spawner native.
- `--no-pins` disables both static and runtime pins.

This is important because the latest run reports all four historical Ardolis pins as NO SPAWN. They must not be forced back into the next .stage.

### Two maximum builds

Run `BUILD_V2_MAX.bat`:

1. **Local-zone MAX** — keeps the proven same-zone template-reference method, profile `max`, and 100% of eligible spawners.
2. **Cross-planet MAX (experimental)** — adds globally catalogued foreign-zone enemy templates using the existing `--cross-planet` path. The builder's byte-level checker can validate the file structure, but only an in-game run can prove the engine accepts every foreign reference.

Both builds are kept separately. The launcher offers installation only after each build passes its own checker. Local-zone MAX is the recommended fallback; cross-planet MAX is explicitly experimental.

### Template-adapter census

Each build also emits `template_adapter_inventory.csv`. It is diagnostic only. The current patch does **not** rewrite generic Template adapters: the exact runtime class, variable ownership, and spawn-context semantics must be classified before changing those nodes. This avoids pretending that all 638 previously counted adapter nodes are safe enemy spawners.

## Validation

New offline unit tests cover verdict precedence, stale-pin suppression, dynamic pin updates, NOT REACHED handling, and `--no-pins`. Run:

```bat
python -I -m unittest discover -s tests -p "test_verdict_policy.py"
```

The full real-zone integration test still requires the user's local game zone file. The cross-planet build still requires in-game validation. No game executable or local game archives are included in this repository patch.
